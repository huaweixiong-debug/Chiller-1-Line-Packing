# EV80 防重码扫码工具

## 功能简介

本工具用于 EV80 生产线激光码防重码检测。通过读取 `.xls` 总表，接收扫码枪或摄像头输入，在同一批次运行中检测重复扫码：

- **无重码**：首次扫码且码值存在于总表中（不代表工艺质量判定）
- **重码**：本次批次内重复扫码，触发声音报警
- **未知码**：码值不存在于总表中，单独提示
- **格式异常**：输入不是 26 位数字激光码，单独提示

> **重要说明**：「无重码」仅表示该码在本次运行批次中首次出现且存在于总表，不代表工艺质量判定。

## 环境要求

- Windows 10/11
- Python 3.8+（如需运行源码版本）
- USB 扫码枪（键盘模拟模式）

## 使用方法

### 方式一：直接运行源码

1. 安装 Python 3.8+
2. 安装依赖：
   ```bash
   pip install xlrd
   ```
3. 运行程序：
   ```bash
   python ev80_code_checker.py
   ```

程序启动时会自动加载与源码同目录的 `ev80 06(1).xls`；也可以在界面中重新选择 `.xls` 文件。

### 方式二：运行构建版本（推荐）

1. 在开发电脑执行构建脚本：
   ```powershell
   powershell -ExecutionPolicy Bypass -File build_exe.ps1
   ```
2. 将 `dist\EV80CodeChecker` 目录复制到目标电脑
3. 将 `.xls` 总表放到同级目录
4. 双击 `EV80CodeChecker.exe` 运行

### 扫码枪配置

1. 将 USB 扫码枪连接到电脑
2. 扫码枪应设置为**键盘模拟模式**（通常通过扫描配置码设置）
3. 确保扫码枪输入焦点在程序的「扫码输入」框中
4. 扫码后自动按回车提交，无需手动点击按钮

### 摄像头功能（可选）

如需使用摄像头解码，需额外安装依赖：

```bash
pip install opencv-python zxing-cpp
```

点击「开启摄像头」按钮启动摄像头扫描模式，界面会显示预览。摄像头支持 QR 码、Data Matrix 和常见一维码。

> **注意**：摄像头解码对光照和角度有一定要求，建议优先使用 USB 扫码枪。

## 界面说明

| 区域 | 说明 |
|------|------|
| 总表文件 | 自动加载或选择和重载 `.xls` 总表文件 |
| 扫码输入 | 输入激光码，支持回车自动提交 |
| 最近状态 | 大字显示最近一次扫码结果 |
| 无重码 | 本次批次首次扫码且在总表中的码列表 |
| 重码 | 本次批次重复扫码的码列表（红色） |
| 未知/格式异常 | 不存在于总表或格式错误的码列表；不会进入无重码 |
| 导出 CSV | 将所有扫码记录导出为 CSV 文件 |

## 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+O` | 选择总表文件 |
| `Ctrl+R` | 重载当前总表 |
| `Ctrl+E` | 导出 CSV |
| `Enter` | 提交扫码输入 |

## 构建

在开发电脑执行：

```powershell
powershell -ExecutionPolicy Bypass -File build_exe.ps1
```

如需跳过依赖安装（已安装时）：

```powershell
powershell -ExecutionPolicy Bypass -File build_exe.ps1 -SkipInstall
```

构建输出位于 `dist\EV80CodeChecker\` 目录。

## 故障排查

### 扫码枪不工作

- 确认扫码枪已设置为键盘模拟模式
- 确认输入焦点在「扫码输入」框中
- 尝试在记事本中测试扫码枪是否正常

### 摄像头无法启动

- 确认已安装 `opencv-python` 和 `zxing-cpp`
- 检查摄像头是否被其他程序占用
- 尝试在设备管理器中确认摄像头状态

### 总表加载失败

- 确认文件是 `.xls` 格式（旧版 Excel）
- 如文件是 `.xlsx` 格式，请先另存为 `.xls`
- 检查文件是否损坏
- 激光码列应在 Excel 中设置为“文本”格式；程序会跳过疑似按数值保存的长码，避免浮点精度丢失造成误判

### 构建失败

- 确认 Python 版本 >= 3.8
- 确认 pip 可正常工作
- 尝试重新安装 PyInstaller：`pip install --upgrade pyinstaller`

## 注意事项

1. 本工具不会修改原始 `.xls` 总表文件
2. 扫码记录仅保存在内存中，退出程序后不保留（请使用导出功能）
3. 「无重码」不代表工艺质量判定，仅表示该码在本次批次中首次出现且存在于总表
4. 建议每次开始新批次前点击「清空批次」按钮
5. 原始 `.xls` 中同一码出现在多个参考工作表时，程序只建立去重后的主码集合，不会因此触发本次批次重码报警
